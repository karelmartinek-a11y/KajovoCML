# Documentation authority

`SSOT_CURRENT.md` is the normative target. Actual current behavior is determined from source code. `ARCHITECTURE.md`, `PROJECT_PHASE.md`, `current-state-manifest.yaml`, ADR 0001 and active runbooks describe the implemented internal-generation architecture.

Files explicitly headed `RETIRED`, `HISTORICAL` or `HISTORICAL/SUPERSEDED` — including ADR 0002, old compliance releases, onboarding catalogs, Dashboard acceptance notes and `DELIVERY_SUMMARY_SSOT_2026-08-09.md` — are forensic/migration context only and must not be used as current creation/deployment instructions.
