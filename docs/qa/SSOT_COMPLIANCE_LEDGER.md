`docs/SSOT_CURRENT.md` or the 160-row
`docs/qa/SSOT_INTEGRATION_MATRIX.md`. Each matrix point is referenced by its
exact numeric ID; the matrix retains the authoritative PASS/FAIL/NOT VERIFIED
status and evidence text. The companion guard
`scripts/test-ssot-compliance-ledger.mjs` rejects missing/duplicate matrix IDs,
unknown statuses and incomplete OWNER coverage.
